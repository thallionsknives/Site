      Textes du site

      Compteur de visites

      Le compteur utilise le service gratuit GoatCounter. Après avoir créé votre compte sur goatcounter.com, indiquez ici le code choisi (la partie avant « .goatcounter.com »). Laissez vide pour ne rien compter.

      Mentions légales

      Ces informations sont obligatoires pour un site qui vend. Complétez-les avant de communiquer l'adresse du site.
